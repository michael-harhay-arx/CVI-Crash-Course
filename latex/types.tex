To create a type, simply right click under the desired type list and follow the resulting pop-\/up menu.\hypertarget{types_typeprops}{}\doxysubsubsection{\texorpdfstring{Data Type Properties}{Data Type Properties}}\label{types_typeprops}
When creating a custom data type, it is important that you correctly configure its properties. To do so, right click the data type and select {\bfseries{Properties}}.

The most important property to be aware of is C Struct Passing, as it allows variables of this data type to be passed into C code modules as C structs. To set up this functionality, follow these steps:\+
\begin{DoxyEnumerate}
\item Click the checkbox titled "{}\+Allow Objects of this Type to be Passed as Structs"{}
\item For each field in the data type, ensure that the type matches the type defined by the corresponding code module parameter.
