\doxysection{Variables }
\hypertarget{vars}{}\label{vars}\index{Variables@{Variables}}
Variables in Test\+Stand work similarly to variables in most programming languages. The following section will detail how they work.\hypertarget{vars_vartypes}{}\doxysubsection{\texorpdfstring{Variable Types}{Variable Types}}\label{vars_vartypes}

\begin{DoxyItemize}
\item {\bfseries{Number}}:\+ encompasses all numeric types.
\item {\bfseries{String}}:\+ note that there is no "{}char"{} variable type, only string.
\item {\bfseries{Boolean}}
\item {\bfseries{Object Reference}}:\+ references an object (similar to a pointer).
\item {\bfseries{Container}}:\+ a structure that can hold members of various data types (similar to a C struct).
\item {\bfseries{Type}}:\+ a user-\/defined datatype.
\item {\bfseries{Array}}
\end{DoxyItemize}\hypertarget{vars_varscope}{}\doxysubsection{\texorpdfstring{Variable Scopes}{Variable Scopes}}\label{vars_varscope}
From smallest to largest:\+
\begin{DoxyItemize}
\item {\bfseries{Step}}:\+ Only exists within the current test step.
\item {\bfseries{Local}}:\+ Only exists within the current sequence.
\item {\bfseries{Parameters}}:\+ Must be passed into the current sequence by the caller sequence.
\item {\bfseries{File\+Globals}}:\+ Global variables that exist everywhere within a sequence file.
\item {\bfseries{Station\+Globals}}:\+ Variables shared across the "{}station"{} (all sequence files have access).
\item {\bfseries{This\+Context}}:\+ The current sequence "{}context"{}.
\item {\bfseries{Run\+State}}:\+ A broad grouping encompassing the Test\+Stand engine and Context, as well as other items.
\end{DoxyItemize}

Note:\+ {\bfseries{This\+Context}} and {\bfseries{Run\+State}} are typically only used when working with the API. However, feel free to familiarize yourself with them.
