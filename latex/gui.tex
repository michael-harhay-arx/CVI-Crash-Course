\begin{DoxyEnumerate}
\item {\bfseries{GUI Editor Pane}}:\+ The region in which GUI editing takes place.
\item {\bfseries{Objects Pane}}:\+ This pane contains a list of present GUI objects.
\item {\bfseries{Object Properties Pane}}:\+ When a GUI object is selected, its properties appear in this pane.
\item {\bfseries{Help Pane}}:\+ This pane displays helpful messages about the current selection.

\hypertarget{gui_guieditorcontrols}{}\doxysubsection{\texorpdfstring{Editing GUI Elements}{Editing GUI Elements}}\label{gui_guieditorcontrols}
To create a GUI element, right click anywhere and select the desired GUI element to add.

Once an element has been added, it can be edited by right clicking and selecting {\bfseries{Edit Control}}. Alternatively, the Object Properties Pane can be used for editing.

To learn more about a GUI element, right click it and select {\bfseries{Control Help}}.
