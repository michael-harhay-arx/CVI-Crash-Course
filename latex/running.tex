\hypertarget{running_modes}{}\doxysubsection{\texorpdfstring{Step Run Modes}{Step Run Modes}}\label{running_modes}
Right-\/clicking on a test step and navigating to {\bfseries{Run Mode}} reveals the available step run modes. These step modes often prove useful while debugging.
\begin{DoxyItemize}
\item {\bfseries{Force to Pass}}:\+ the test step always passes regardless of the actual test result.
\item {\bfseries{Force to Fail}}:\+ the test step always fails regardless of the actual test result.
\item {\bfseries{Skip}}:\+ the test step is skipped during sequence execution (used to "{}comment out"{} steps).
\item {\bfseries{Normal}}:\+ the test step runs normally.
\end{DoxyItemize}\hypertarget{running_running}{}\doxysubsection{\texorpdfstring{Running the Sequence}{Running the Sequence}}\label{running_running}
There are a few ways to run a Test\+Stand sequence. To see these options, hover over {\bfseries{Execute}}.
\begin{DoxyItemize}
\item {\bfseries{Test UUTs}}:\+ Runs the sequence utilizing the station model.
\item {\bfseries{Single Pass}}:\+ The same as {\bfseries{Test UUTs}}, but only tests one UUT.
\item {\bfseries{Run Main\+Sequence}}:\+ Runs the Main\+Sequence directly without using the station model (useful for debugging).
\end{DoxyItemize}\hypertarget{running_running2}{}\doxysubsection{\texorpdfstring{Running Selected Steps}{Running Selected Steps}}\label{running_running2}
To run a subset of steps from a sequence, select the desired steps within the Steps Pane and right click, selecting {\bfseries{Run Selected Steps}}. This can also be done from {\bfseries{Execute \texorpdfstring{$>$}{>} Run Selected Steps}}.\hypertarget{running_debug}{}\doxysection{\texorpdfstring{Debugging}{Debugging}}\label{running_debug}
Debugging a Test\+Stand sequence can be approached similar to conventional code debugging.\hypertarget{running_analyze}{}\doxysubsection{\texorpdfstring{Sequence Analyzer}{Sequence Analyzer}}\label{running_analyze}
Test\+Stand\textquotesingle{}s sequence analyzer is a tool that will attempt to point out potential issues in a sequence. It can be run via {\bfseries{Debug \texorpdfstring{$>$}{>} Sequence Analyzer \texorpdfstring{$>$}{>} Analyze "{}\+Sequence\+File\+Name.\+seq"{}}}. Additionally, it can be automatically set to run before any execution, via {\bfseries{Debug \texorpdfstring{$>$}{>} Sequence Analyzer \texorpdfstring{$>$}{>} Toggle Analyze File Before Executing}}.

Sequence analysis results will populate in the Analysis Results Pane, which is in the same location as the Step Settings Pane.\hypertarget{running_breakpoints}{}\doxysubsection{\texorpdfstring{Breakpoints \& Watch Expressions}{Breakpoints \& Watch Expressions}}\label{running_breakpoints}
Breakpoints can be set by navigating to {\bfseries{Debug \texorpdfstring{$>$}{>} Breakpoints/\+\+Watches}}, and adding a breakpoint via the resulting menu. Note that watch expressions can also be set from within the menu.

Alternatively, clicking within the white space directly to the left of a test step will enable a breakpoint.

\hypertarget{running_stepcommands}{}\doxysubsection{\texorpdfstring{Step Commands}{Step Commands}}\label{running_stepcommands}
While executing a sequence with breakpoints, standard debugging step commands can be used. They can be found under {\bfseries{Debug}}; here are some of the most useful ones:\+
\begin{DoxyItemize}
\item {\bfseries{Resume}}:\+ Resumes execution until the next breakpoint is reached (F5).
\item {\bfseries{Step Over}}:\+ Steps over the current test step without resuming execution (F8).
\item {\bfseries{Step Into}}:\+ Steps into the current test step (F10). Especially useful for stepping into the source code of a code module. 
\end{DoxyItemize}
