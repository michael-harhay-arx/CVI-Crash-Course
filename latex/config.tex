\chapter{Configuration \& Options }
\hypertarget{config}{}\label{config}\index{Configuration \& Options@{Configuration \& Options}}
CVI contains a number of menus containing configuration settings and options. This section of the guide will briefly list the most important settings and their recommended states.\hypertarget{config_buildsettings}{}\doxysection{\texorpdfstring{Build Settings}{Build Settings}}\label{config_buildsettings}
\hypertarget{config_buildconfig}{}\doxysubsection{\texorpdfstring{Build Configurations}{Build Configurations}}\label{config_buildconfig}
Can be accessed via {\bfseries{Build \texorpdfstring{$>$}{>} Configuration}}. The resulting dropdown lists the available build configurations; more can be added by selecting {\bfseries{Manage Configurations}}. The main configurations are:\+
\begin{DoxyItemize}
\item {\bfseries{Debug}}:\+ This configuration allows for debugging.
\item {\bfseries{Release}}:\+ This configuration does not allow debugging, and is the most optimized for release.
\item {\bfseries{Debug64}}:\+ 64-\/bit version of {\bfseries{Debug}}.
\item {\bfseries{Release64}}:\+ 64-\/bit version of {\bfseries{Release}}.  
\begin{DoxyImage}%
\includegraphics[width=0.400000\textwidth]{BuildConfig.png}%
\doxyfigcaption{Build Configuration Menu}%
\end{DoxyImage}

\end{DoxyItemize}\hypertarget{config_buildtargettype}{}\doxysubsection{\texorpdfstring{Build Target Type}{Build Target Type}}\label{config_buildtargettype}
Can be accessed via {\bfseries{Build \texorpdfstring{$>$}{>} Target Type}}. The resulting dropdown lists the available build target types:\+
\begin{DoxyItemize}
\item {\bfseries{Executable}}:\+ a standalone application that can be executed.
\item {\bfseries{Dynamic Link Library (DLL)}}:\+ a library file that is linked at run time. DLLs are less portable and are not self-\/contained, but offer easier maintenance (simply replace the desired DLL without needing to recompile everything) and take up less space.
\item {\bfseries{Static Library}}:\+ a library file that is linked at compile time. Static libraries have the advantage of being self-\/contained, however they are much larger. Additionally, any updates a static library require recompiling.  
\begin{DoxyImage}%
\includegraphics[width=0.400000\textwidth]{TargetType.png}%
\doxyfigcaption{Build Target Type Menu}%
\end{DoxyImage}

\end{DoxyItemize}\hypertarget{config_buildtarget}{}\doxysubsection{\texorpdfstring{Build Target Settings}{Build Target Settings}}\label{config_buildtarget}
