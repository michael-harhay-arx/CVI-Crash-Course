Test\+Stand contains many step types, which can be used to build test sequences. Here are a few of the most commonly used step types:\+\hypertarget{steps_action}{}\doxysubsubsection{\texorpdfstring{Action}{Action}}\label{steps_action}
Calls a code module that does not perform a test. For example, an action step might initialize an instrument to prepare it for testing.  
\begin{DoxyImageNoCaption}%
  \doxymbox{\includegraphics[width=0.060000\textwidth]{action_steptype.png}}%
\end{DoxyImageNoCaption}
\hypertarget{steps_pf}{}\doxysubsubsection{\texorpdfstring{Pass/\+\+Fail}{Pass/\+\+Fail}}\label{steps_pf}
Calls a code module that makes its own pass/\+fail determination. Note that this module does not appear by default in the Insertion Palette; to insert a pass/\+fail step, right click the Steps Pane and select {\bfseries{Insert Step \texorpdfstring{$>$}{>} Tests \texorpdfstring{$>$}{>} Pass/\+\+Fail Test}}. Within this menu are a few other types of code module tests.  
\begin{DoxyImageNoCaption}%
  \doxymbox{\includegraphics[width=\textwidth,height=\textheight/2,keepaspectratio=true]{pf_steptype.png}}%
\end{DoxyImageNoCaption}
\hypertarget{steps_sc}{}\doxysubsubsection{\texorpdfstring{Sequence Call}{Sequence Call}}\label{steps_sc}
Calls another sequence in the current sequence file or in another sequence file.  
\begin{DoxyImageNoCaption}%
  \doxymbox{\includegraphics[width=0.100000\textwidth]{seqcall_steptype.png}}%
\end{DoxyImageNoCaption}
\hypertarget{steps_statement}{}\doxysubsubsection{\texorpdfstring{Statement}{Statement}}\label{steps_statement}
Executes a Test\+Stand expression. For example, a statement step can be used to increment the value of a local variable. Note that statement steps do not return a pass/\+fail status by default; step status can be set in the Step Settings Pane under {\bfseries{Properties \texorpdfstring{$>$}{>} Expressions \texorpdfstring{$>$}{>} Status Expression}}.  
\begin{DoxyImageNoCaption}%
  \doxymbox{\includegraphics[width=0.080000\textwidth]{statement_steptype.png}}%
\end{DoxyImageNoCaption}
\hypertarget{steps_flowctrl}{}\doxysubsubsection{\texorpdfstring{Flow Control}{Flow Control}}\label{steps_flowctrl}
Flow control step types implement standard programming branching statements.

\hypertarget{steps_workwithsteps}{}\doxysubsection{\texorpdfstring{Working with Test Steps}{Working with Test Steps}}\label{steps_workwithsteps}
\hypertarget{steps_createteststep}{}\doxysubsubsection{\texorpdfstring{Creating a Test Step}{Creating a Test Step}}\label{steps_createteststep}
To create a test step, simply drag and drop from the Insertion Palette into the Steps Pane. Alternatively, right click within the Steps Pane and select {\bfseries{Insert Step \texorpdfstring{$>$}{>} Desired step type}}.\hypertarget{steps_editteststep}{}\doxysubsubsection{\texorpdfstring{Editing a Test Step}{Editing a Test Step}}\label{steps_editteststep}
To edit a step, select it in the Steps Pane and navigate to the Step Settings Pane if it is not already open. Within the Step Settings Pane, there are typically (but not always) two tabs:\+ {\bfseries{Properties}} and {\bfseries{Step-\/\+Specific Settings}}. Take some time to try experimenting with these tabs within multiple step types.\hypertarget{steps_stepprops}{}\doxysubsubsubsection{\texorpdfstring{Step Properties}{Step Properties}}\label{steps_stepprops}
The {\bfseries{Properties}} tab is a standard set of properties that appear in all Test\+Stand step types.  
\begin{DoxyImage}%
\includegraphics[width=0.850000\textwidth]{stepproperties.png}%
\doxyfigcaption{Step Properties Tab}%
\end{DoxyImage}


There are a few key properties to note, all of which are used often at Arxtron (see \doxysectlink{flow_stepflow}{Test Step Flow}{1} for more details):\+
\begin{DoxyItemize}
\item {\bfseries{Post Actions}}:\+ Determines how the sequence should behave depending on the result of the current test step.
\item {\bfseries{Expressions}}:\+ Pre-\/ and Post-\/\+Expressions are Test\+Stand expressions that will run before and after the execution of the current step. The Status Expression determines the output status of the test (pass/\+fail)
\item {\bfseries{Preconditions}}:\+ A Test\+Stand expression that determines whether or not the current step is run in the sequence, via a logical condition.
\end{DoxyItemize}\hypertarget{steps_stepsettings}{}\doxysubsubsubsection{\texorpdfstring{Step-\/\+Specific Settings}{Step-\/\+Specific Settings}}\label{steps_stepsettings}
{\bfseries{Step-\/\+Specific Settings}} vary between test step types.

For example, an Action test step\textquotesingle{}s settings primarily concerns the passing of parameters between Test\+Stand and the code module.
