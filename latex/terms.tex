\chapter{Terminology }
\hypertarget{terms}{}\label{terms}\index{Terminology@{Terminology}}
Briefly familiarize yourself with the following terms before continuing, as they will be referenced throughout the guide.


\begin{DoxyDescription}
\item[{\parbox[t]{\linewidth}{{\bfseries{\label{terms_term_sequence_file}%
\Hypertarget{terms_term_sequence_file}%
Sequence File}} }}]\hfill \\
A file type that can be opened via a \href{\#term_test_executive}{\texttt{test executive}}. For example, Test\+Stand works with .seq files. A sequence file typically contains one or more \href{\#term_sequence}{\texttt{test sequences}}. 


\item[{\parbox[t]{\linewidth}{{\bfseries{\label{terms_term_test_executive}%
\Hypertarget{terms_term_test_executive}%
Test Executive}} }}]\hfill \\
A high-\/level application that can be used to manage, write, and execute \href{\#term_sequence}{\texttt{test sequences}}. Test\+Stand is an example of a \href{\#term_test_executive}{\texttt{test executive}}.  
\end{DoxyDescription}
