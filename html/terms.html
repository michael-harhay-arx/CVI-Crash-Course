Terminology

Briefly familiarize yourself with the following terms before continuing, as they will be referenced throughout the guide.

Sequence File

A file type that can be opened via a test executive. For example, TestStand works with .seq files. A sequence file typically contains one or more test sequences.

Test Executive

A high-level application that can be used to manage, write, and execute test sequences. TestStand is an example of a test executive.

Test Sequence

A collection of test steps. Often simply referred to as a "sequence" within TestStand; be sure to distinguish between "sequences" and sequence files.

Test Step

A singular test, often taking place within a test sequence.

UUT
Stands for Unit Under Test.
