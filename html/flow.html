TestStand Flows

Sequence Flow

TestStand follows a standard order of sequences within a sequence file, outlined by the following flowchart. If the following sequences do not appear in TestStand, navigate to Edit > Sequence File Callbacks. From that menu, you can add default TestStand callback sequences.

  1. ProcessSetup: Used for program setup (e.g. starting threads, initializing libraries).
  2. PreBatch: If batch model is active, runs before each batch.
  3. PreUUT: Runs before each UUT.
  4. MainSequence: Primary test sequence to be run.
  5. PostUUT: Runs after each UUT.
  6. PostBatch: If batch model is active, runs after each batch.
  7. ProcessCleanup: Used for program cleanup.

Test Step Flow

TestStand also follows a standard procedure within each test step, as outlined below.

  1. Preconditions: See Step Properties.
  2. Loop Initialization Expression: Used to initialize loop variables (e.g. int i = 0).
  3. Pre-Expression: See Step Properties.
  4. Module Action: Main module action.
  5. Post-Expression: See Step Properties.
  6. Status Expression: Determines pass/fail status of step.
  7. Loop Increment Expression: Increments loop variables (e.g. i++).
  8. Loop While Expression: Checks loop condition (e.g. i < 10).
  9. Loop Status Expression: Determines pass/fail status of loop.
  10. Post Actions: See Step Properties.
