Tips & Tricks

The following tips and tricks are helpful to know.

General Tips & Tricks

  • Help Menu: Press F1 to access the CVI help documentation.
  • Generate Prototype: Select Build > Generate Prototypes to generate a file containing declarations for global and static functions, as well as external declarations for global variables. These can be copied into your existing source and header files.
  • Tags: Select a line and press Shift+F2 to "tag" or "bookmark" that line. Then, press F2 to cycle through all tagged lines.

Hotkeys

  • Comment Selection: Select code to comment out, press Ctrl+F3
  • Uncomment Selection: Select code to uncomment, press Ctrl+F4
  • Show Function Prototype: Place cursor in function, press Ctrl+Shift+Space
  • Find: Ctrl+F
  • Replace: Ctrl+H
  • Go to line: Ctrl+L
  • Build project: Ctrl+M
  • Build specific file within project: Ctrl+K
  • Go to line: Select item to check defition of, press Ctrl+I
  • Go back: After going to definition via Ctrl+I, press Ctrl+G to go back
