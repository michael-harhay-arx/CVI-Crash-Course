Types

TestStand supports the creation of custom variable and step types. This functionality can be accessed from the Types Pane.

The Types Pane

The Types Pane can be opened via View > Types or by pressing Ctrl+T.

Types Pane

Working with Types

Creating a Type

To create a type, simply right click under the desired type list and follow the resulting pop-up menu.

Data Type Properties

When creating a custom data type, it is important that you correctly configure its properties. To do so, right click the data type and select Properties.

The most important property to be aware of is C Struct Passing, as it allows variables of this data type to be passed into C code modules as C structs. To set up this functionality, follow these steps:

  1. Click the checkbox titled "Allow Objects of this Type to be Passed as Structs"
  2. For each field in the data type, ensure that the type matches the type defined by the corresponding code module parameter.
